# Student AI Credit Costs

## Principle
- simple explanation / summary / planning = low cost
- quiz / revision sheet / correction = medium cost
- oral / slides / advanced project brief = higher cost

## Current code direction
- summary and method commands are light
- slides, site, app, game and agent briefs are more expensive

## Important rule
- no debit on total failure must stay enforced at the server or billing layer
- this run does not re-prove real billing behavior
