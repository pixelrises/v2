# Student AI Product Spec

## Promise
Help a student understand, revise, present and structure work without replacing the effort.

## Core jobs
- understand a lesson
- compress a course into a useful revision format
- train actively
- prepare oral presentations
- build slides
- correct work with method
- organize revision time
- prepare digital project briefs

## Output rules
- educational first
- structured
- reusable
- honest
- no fake sources
- no fake completion

## Product boundary
- Student AI learns and prepares
- Builders create
- Agent Studio configures agents
