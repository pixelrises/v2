# Student AI Source Strategy

## Rules
- never invent sources
- never invent quotes
- never invent statistics
- ask the user to provide the source or verify externally if live web is not available

## Supported workflow
- research question
- search queries
- validation criteria
- summary format
- bibliography formatting if sources are supplied

## Status
- logic prepared in prompt and commands
- live web sourcing should stay explicit and server-controlled
