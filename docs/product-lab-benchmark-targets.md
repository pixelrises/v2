

# Product Lab - Benchmark Targets

Le Product Lab doit ameliorer toute la V2 sans copier les plateformes d'inspiration.

| Module | Inspiration adaptee | Niveau cible Pixelrises |
| --- | --- | --- |
| Dashboard | Shopify Admin / Linear / Base44 | Un cockpit decisionnel qui montre l'etat du business, la prochaine action et les signaux reels. |
| Site Builder | Lovable / v0 / Vercel | Un flow idee -> plan -> preview -> amelioration fluide, premium et oriente conversion. |
| Agent Builder | Delos / Base44 | Un studio d'agents simple, puissant, avec permissions claires et actions validables. |
| Game Builder | Roblox Creator Hub / Minecraft Creator / UEFN | Un generateur beta de blueprints, snippets, assets et checklists sans promesse de publication automatique. |
| Multi-IA / Systeme | Vercel AI Gateway / 21st.dev | Un orchestrateur modulaire, normalise, teste, avec fallback et couts controles. |
| Integrations / Templates | 21st.dev / Mobbin / Vercel | Des registries clairs, honnetes, reutilisables et adaptes aux projets business. |

Regle centrale:
Chaque patch doit aider l'utilisateur a creer, ameliorer, publier, connecter ou analyser un projet V2.
